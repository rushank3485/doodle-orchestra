# 🎶 Doodle Orchestra

Draw on a canvas and a sweeping playhead turns your doodle into music.

**Live demo:** _add your GitHub Pages link here_

## How it works
- **Height** sets the pitch (snapped to a scale so it always sounds good)
- **Color** sets the instrument: bell, bass, pluck or drum
- **Size** sets the volume
- Pick a scale (pentatonic, major, minor, chromatic) and tempo, or hit **Surprise me**

## Tech
Plain HTML, CSS and JavaScript. Canvas for drawing, Web Audio API for synthesis. No libraries, no build step, no API keys.

## Run it
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Push `index.html` and this README to a new repo
2. Go to **Settings → Pages**
3. Set the source to the `main` branch, root folder, and save
